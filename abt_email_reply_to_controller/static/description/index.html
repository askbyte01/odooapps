Email Reply to Controller

Overview

  • This feature allows users to manage email replies effectively by configuring the "Reply-To" field in email templates.

How It Works

  • Navigate to Email Templates in Odoo.
  • Add an email address (or placeholder) in the "Reply-To" field.
  • When sending an email using a configured template, the "Reply-To" address is automatically set in the email, ensuring seamless reply routing.
  • The system automatically applies the "Reply-To" value from the template to the email.
