✨ POS Discount Without Discount Product ✨

Simplify discounts in POS – no fake products required

📖 Overview

This module makes discount handling in Odoo Point of Sale much simpler. Instead of creating a separate discount product, the discount is applied directly on order lines, keeping your POS orders and receipts clean.

🚀 Key Features

  • ✔ Directly apply % discount on POS product lines
  • ✔ Supports per-line & global discount application
  • ✔ Avoids unnecessary "discount product" clutter
  • ✔ Works with Odoo POS v16
  • ✔ Easy setup – just install & use
