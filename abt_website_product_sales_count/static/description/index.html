Website Product Sold Count

Show product popularity directly on your Odoo website

Key Features

Smart
Enable / Disable Per Product

Show or hide sold count using a simple checkbox on the product form.

Auto
Automatic Count

Total purchase count is calculated automatically from sales orders.

Clean
Number Formatting

Large values are formatted nicely like 1k, 1k+, 2.5k+.

Safe
Zero-Value Handling

Nothing is shown if product is never purchased or feature is disabled.

How It Works

Enable the feature directly from product configuration.

Create and confirm sales orders as usual.

Customers will see sold count on product page.
